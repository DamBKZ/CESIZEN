L'encart pseudo et email vous permet de modifier votre pseudo et/ou votre adresse email.

Pseudo @if (form.controls.pseudo.hasError('required')) { Le pseudo est obligatoire. } @if (form.controls.pseudo.hasError('minlength')) { Le pseudo doit contenir au moins 2 caractères. } @if (form.controls.pseudo.hasError('maxlength')) { Le pseudo ne peut pas dépasser 30 caractères. } Email @if (form.controls.email.hasError('required')) { L'adresse email est obligatoire. } @if (form.controls.email.hasError('email')) { L'adresse email n'est pas valide. }
